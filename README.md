# Chocolatka

Личный таск-менеджер с матрицей Эйзенхауэра. Веб-приложение для приоритизации личных и рабочих задач, ведения календаря с дедлайнами, настройки повторений и напоминаний, а также базовой аналитики выполнения.

## Особенности проекта
Главная особенность — визуальная приоритизация через матрицу Эйзенхауэра на главном экране. Пользователь создает задачу и перетаскивает её в один из 4 квадрантов, мгновенно меняя её приоритет. 

*Важное примечание:* На текущем этапе интерактивная матрица и календарь являются рабочим прототипом. Функции вроде полной кастомизации цветов, расширенной аналитики (тренды, серии) и drag-and-drop задач непосредственно в календаре запланированы на вторую версию.

## Стек технологий
- **React 18** — библиотека для построения интерфейса
- **TypeScript** — типизированный JavaScript
- **Vite** — сборщик проекта
- **Tailwind CSS 3** — стилизация
- **React Router DOM** — навигация между страницами (HashRouter для корректной работы на статических хостингах)
- **Lucide React** — иконки

## Реализованный функционал (MVP)
- Главная страница с матрицей Эйзенхауэра (4 квадранта, drag-and-drop задач).
- Календарь с масштабами: день / неделя / месяц (отображение задач с дедлайном).
- Создание, редактирование и удаление задач с привязкой к проектам и тегам.
- Настройка базовых повторений (ежедневно/еженедельно/ежемесячно/ежегодно) и одного напоминания на задачу.
- Страница статистики: общее количество задач, % выполнения, просроченные, круговая диаграмма по проектам/квадрантам.
- Адаптивная верстка (на мобильных устройствах матрица отображается квадратом 2×2 с возможностью сворачивания).
- Сохранение состояния (избранное, созданные темы) в `localStorage` браузера (для демо-режима).

## Как запустить проект локально
Для запуска потребуется установленный Node.js.

1. Клонируйте репозиторий или скачайте архив.
2. Установите зависимости:
   ```bash
   npm install
3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере: `http://localhost:5173`

## Структура проекта
- `src/components/` — переиспользуемые UI-компоненты (карточки задач, квадранты, кнопки, фильтры).
- `src/pages/` — страницы приложения (Главная, Календарь, Статистика, Профиль).
- `src/store/` — глобальное состояние приложения (Context API).
- `src/data/` — статические или моковые данные для демонстрации.
- `src/types.ts` — типы данных TypeScript.
